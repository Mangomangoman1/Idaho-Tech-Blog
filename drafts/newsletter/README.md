# Idaho Tech Briefing drafts

Weekly newsletter drafts for the editor's review. Nothing here is sent or linked from the site.

- `issue-001.html`: email-ready HTML (table layout, inline styles, noindex). The dark banner at the top is for review only; remove it before sending.
- `issue-001.txt`: plain-text version for the same send.
- `{{ unsubscribe_url }}` and `{{ mailing_address }}` are placeholders the email service fills in. US law (CAN-SPAM) requires a working unsubscribe link and a postal address (a PO box is fine) in every commercial-style email.

No newsletter service is connected yet. The homepage "Idaho Tech Briefing" block only links to /submit.html.
